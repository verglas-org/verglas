# Contributing to Verglas OS

At this time, we are not seeking broad outside contribution.

AI has made writing code easy. The hard part is reviewing it, keeping quality
high, and keeping the product coherent. Large external PRs tend to donate the
easy part of the job while creating more of the hard work.

We are happy to accept small, trivially-verified PRs that fix a clear problem.
Please avoid low-value noise (e.g. drive-by typo PRs) and changes larger than a
dozen or so lines unless coordinated first.

If you have a substantial idea, open a discussion or issue before investing in a
large diff. Prefer changes that advance the lakehouse / containerized Verglas
runtime direction described in [docs/architecture.md](docs/architecture.md).

This policy may change as the project matures.
