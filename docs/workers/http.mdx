---
title: "HTTP callbacks"
description: "Expose a worker callback path and ingest the requested market-data interval."
icon: "webhook"
---

An HTTP trigger turns a declared path into a bounded worker event. Verglas
stores the complete method, path, headers, and body in an
`org.verglas.http.request` CloudEvent; the scheduler does not keep the client
connection open while the job runs.

The manifest from [Worker overview](/docs/workers/overview) declares:

```toml
[[triggers]]
type = "webhook"
path = "/market-data/daily-bars"
```

Request July 2026 bars:

```bash
curl --fail-with-body \
  --request POST \
  --header 'Content-Type: application/json' \
  --header 'Idempotency-Key: market-data-http-2026-07' \
  --data '{"start":"2026-07-01T00:00:00Z","end":"2026-08-01T00:00:00Z"}' \
  http://127.0.0.1:8334/v1/http/market-data/daily-bars
```

The body is copied into the CloudEvent. `ingest.py` decodes it and requests the
half-open interval `[start, end)` from Yahoo Finance.

Verify the requested dates:

```bash
verglas query \
  analytics \
  "SELECT min(timestamp), max(timestamp), count(*)
   FROM market.ohlcv
   WHERE timestamp >= '2026-07-01' AND timestamp < '2026-08-01'"
```
