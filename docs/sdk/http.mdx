High-level SDKs stay hand-written; OpenAPI is for REST visibility and CI.

## Execution

<!-- op:connect -->
**connect** — SDK-only session setup (bearer auth). No HTTP route.

<!-- op:ensure_table -->
**ensure_table** — Iceberg REST `GET/POST …/v1/namespaces/{ns}/tables…` (not Verglas `/v1/tables`). TypeScript: `ensureTable`. Rust: `ensure_table`.

<!-- op:query -->
**query** — `POST /v1/databases/{database}/query`. TypeScript JSON. Rust Arrow IPC stream. The named database must be an active Lakehouse; Postgres SQL uses a separate runtime contract.

<!-- op:append -->
**append** — TypeScript/CLI: `POST /v1/ingest/{name}` (JSONL/files). Rust: `POST /v1/write/{name}` (Arrow IPC).

<!-- op:ingest -->
**ingest** — `POST /v1/ingest/{name}` file create/append (CLI). TypeScript append reuses this route.

<!-- op:namespace -->
**namespace** — `GET /v1/namespaces`, `GET /v1/namespaces/{namespace}`, `POST …/invoke/{method}`.

<!-- op:kv -->
**kv** — `GET /v1/kv/{namespace}`, `GET|PUT|DELETE /v1/kv/{namespace}/{*key}`.
