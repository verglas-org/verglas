---
title: "Connect Rill"
description: "Run Rill independently against Verglas Iceberg and S3 endpoints."
---

Rill is an external analytics application, not a Verglas service. Verglas does
not start Rill, manage its project files, expose dashboard routes, or require a
durable Rill volume.

<Note>
  Migration note: the Compose Analytics profile and `verglas dashboard`
  command were removed. Upgrading Verglas does not delete an existing
  `rill-data` volume or any user-authored Rill project.
</Note>

On Verglas OS, install Rill as a stateless container application. The OS gives
the container scoped catalog and table credentials and routes its UI through the
application surface. Project definitions come from the application manifest or
state stored outside the container; materializations are rebuildable cache.

For a self-hosted deployment, run Rill separately and configure it with:

- the Iceberg table metadata or catalog information Rill requires;
- the Verglas S3-compatible endpoint, port `8333`, as the object-store endpoint;
- a Verglas S3 access key scoped to the tables the application may read; and
- the region configured for the backing object store.

Rill then reads Iceberg metadata and data through standard interfaces. Exported
and user-authored project files remain valid Rill inputs.
