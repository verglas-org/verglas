---
title: "Engine roles"
description: "Deploy the cache node with optional catalog observation and WAL durability."
icon: "server"
---

Verglas exposes the cache node as its public engine process. Its reusable
components remain libraries, not separately deployed query or write products.

`verglas-cache-node` owns the S3 protocol, S3 Vectors and Graph REST-JSON
surfaces, cache tiers, catalog observation, ring traffic, block devices, and
WAL ingress. It never schedules user code or provides hosted tenant control.

Iceberg engines use the catalog REST endpoint and the cache-node S3 listener.
The `verglas-writeback` library retains the erasure-coded write-back protocol;
it is linked into engine components rather than published as a node product.
