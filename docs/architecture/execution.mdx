Verglas has exactly six products: Worker, Durable Object, Stream, Pipeline,
Sink, and Catalog. Each prebuilt system product is a Worker/DO deployment. The
[Worker primitives platform](/docs/architecture/primitives-platform) is the
normative inventory and PP1–PP10 acceptance page. The composition described
here is a target where its status is not otherwise marked.

## Worker and Durable Object execution

A **Worker** is stateless, pool-executed code. It has no identity or storage;
its bindings are its authority. A **Durable Object** is a named stateful Worker
class with strictly serialized events and one embedded Turso `0.7.2` database.
The local database is a working copy of one remote Turso database dedicated to
that DO. An external lease-fenced sync ingress validates placement before
forwarding `push()`; it is not a second SQL commit engine.

A DO event commits KV/SQL/alarm/attachment state in one Turso transaction. The
host confirms the remote push before releasing event effects. Selected committed
changes may also create transactional outbox rows for a Stream. The Stream
deduplicates `(object-id, event-sequence, record-index)` identities, so a crash
between Stream confirmation and the delivered mark causes an idempotent resend.

A DO has no custom SQLite pager, DataFusion transaction provider, Arrow mutation
envelope, lease-fenced S3 CAS SQL authority, direct Iceberg offloader, or
vector/graph mutation domain. DataFusion may be used inside a Pipeline's
stateless SQL transform only; it is not part of DO storage.

## Prebuilt data products

- **Stream** is a prebuilt DO that durably appends ordered JSON. It does not
  offload, execute SQL, own consumer offsets, or call Iceberg/Catalog.
- **Pipeline** is a prebuilt Worker/DO that owns a Stream cursor, executes
  stateless SQL transforms, batches records, and retries Sink delivery. It
  contains no destination-specific Iceberg code.
- **Sink** is a prebuilt Worker/DO with an idempotency ledger. Its first adapter
  writes Parquet and commits Iceberg through a Catalog binding.
- **Catalog** is a prebuilt Worker/DO that exposes Iceberg REST and reuses the
  existing Verglas catalog and object-storage libraries. It owns metadata
  publication, not Pipeline cursors or Sink delivery state.

## Shared runtime capabilities

`verglas-runtime` is the shared Wasmtime host for Worker and Durable Object
components. It owns the Turso adapter, Foyer memory and disk tiers, origin
access, and narrow privileged capabilities such as Iceberg Catalog commits.
Tenant components do not receive raw object-store, filesystem, or network
authority. See [architecture overview](/docs/architecture/overview) for the
repository boundary.
