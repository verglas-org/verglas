Verglas is an Iceberg-aware object cache and storage engine. Query engines use
its S3 endpoint while the customer's object store and Iceberg catalog remain
authoritative.

<Warning>
Verglas is a pre-release prototype. Configuration, wire formats, and on-disk
layouts may change between commits.
</Warning>

The CLI, SDKs, their documentation, and RIME live in this repository. Hosted
access, scheduling, databases, integrations, applications, workers, and agents
live in the private `verglas-cloud` repository.
