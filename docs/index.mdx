Verglas is the lakehouse runtime: an Iceberg-native statekeeper that makes
data on object storage live. Query engines use its S3 endpoint while the
customer's object store and Iceberg catalog remain authoritative.

<Warning>
Verglas is a pre-release prototype. Configuration, wire formats, and on-disk
layouts may change between commits.
</Warning>

access, scheduling, databases, integrations, applications, workers, and agents
