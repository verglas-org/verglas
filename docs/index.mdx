Verglas has exactly six products: Worker, Durable Object, Stream, Pipeline,
Sink, and Catalog. Worker is stateless. Durable Object is a Turso-backed
stateful Worker class. Stream, Pipeline, Sink, and Catalog are prebuilt
Worker/DO deployments. Read the [normative platform
page](/docs/architecture/primitives-platform) for the complete definitions and
PP1–PP10 criteria.

The same repository contains independent S3/cache, Iceberg, catalog, and
semantic graph/vector infrastructure. Those layers remain useful to
self-hosted query engines and external clients; they are not extra products.

## Install the TypeScript SDK

```sh
npm install @verglas/sdk
```

## Run the cache infrastructure

The cache node ships as a container image. Point it at an S3-compatible origin
and start it:

```sh
docker pull ghcr.io/verglas-org/verglas-cache-node:latest
```

The node serves S3 on `:8333` and health, catalog gateway, and metrics on
`:8334`. See [self-hosting](/docs/get-started/self-host) for provider profiles
and required environment variables.
