Verglas is the lakehouse runtime: an Iceberg-native statekeeper that makes data
on object storage live. Query engines talk to its S3 endpoint, while your
object store and Iceberg catalog stay authoritative. Turn Verglas off and your
lakehouse still works — just slower.

## Install the CLI

```sh
curl -fsSL https://verglas.dev/install.sh | sh
```

## Run the engine

The engine ships as a container image. Point it at an S3-compatible origin and
start it:

```sh
docker pull ghcr.io/verglas-org/verglas-cache-node:latest
```

The node serves S3 on `:8333` and health, catalog gateway, and metrics on
`:8334`. See [self-hosting](/docs/get-started/self-host) for the provider
profiles and the environment each one needs.
